# File map

- `Jm3a Hunt PROMPT.txt` — user's master product prompt (vision, full requirements)
- `CLAUDE.md` — agent rules and commands; `AGENTS.md` — Next.js agent note (re-created by `next dev`)
- `docs/SPEC.md` — technical contracts: data model, API, WS protocol, engine rules, design system
- `docs/PLAN.md` — task list and status
- `README.md` — setup, scripts, env vars, phone testing, Render + Turso deploy, architecture, GPS limits, privacy, feature checklist; `.env.example` (every variable, no secrets); `render.yaml` (Render Blueprint)
- `package.json` — scripts: dev / build / start / test / test:e2e / typecheck / lint / db:generate / db:migrate; `playwright.config.ts` (e2e on port 3100, temp DB, sim GPS)
- `next.config.ts`, `tsconfig.json` (`@/*` → `src/*`), `eslint.config.mjs`, `vitest.config.mts`, `components.json` (shadcn), `drizzle.config.ts`
- `server/index.ts` — entry: loads `.env` (real env wins), starts the app server (Next + API + WS) on `PORT`; SIGTERM/SIGINT snapshot matches, then exit
- `server/app.ts` — `createAppServer({ withNext, config?, now?, autoTick? })`: one HTTP server; `/api/*` → Hono, `/ws` upgrade → gateway, other upgrades (HMR) → Next; binds 0.0.0.0 in production
- `server/config.ts` — env parsing (zod); dev generates missing secrets once into `data/dev-secrets.json` (`devSecret`), production throws; `config.test.ts`
- `server/context.ts` — `createContext`: opens + migrates the DB, rate limiters, engine registry (restores live matches); injectable `now()`
- `server/db/schema.ts` — Drizzle schema (SPEC §4; never coordinates); `client.ts` — `openDb` (libSQL file or Turso) + `migrateDb`; `migrate.ts` — `npm run db:migrate`
- `drizzle/` — generated SQL migrations (`npm run db:generate`); also applied automatically on boot
- `server/auth/index.ts` — session tokens (sha256 in DB, cookie `jh_session`), bcrypt passwords, `userForToken`
- `server/security/` — `rateLimit.ts` (token buckets, SPEC §5 limits), `origin.ts` (Origin check, client IP, cookie parse), `tagToken.ts` (HMAC QR token + 6-digit code, 30 s windows)
- `server/http/` — Hono API (SPEC §6): `index.ts` (middleware: origin, session, rate limit, errors), `auth.ts` (auth + /me), `groups.ts` (groups, members, invites, join, presets), `matches.ts` (create, history, info, settings/zones PUT, results), `dto.ts` (response mappers + authz helpers), `util.ts`
- `server/ws/index.ts` — WebSocket gateway (SPEC §7): cookie + Origin on upgrade, hello re-checks membership, ordered per-socket handling, hb, idle sockets closed
- `server/engine/` — `runtime.ts` (`MatchRuntime`: lobby, consent, preflight, timers, pause, location pipeline, pings, captures, jail/rescue, victory, events, views, snapshots, dev bots), `registry.ts` (runtimes, 1 s tick, restore on boot, shutdown), `store.ts` (DB writes, no coordinates)
- `src/app/` — routes. `layout.tsx` (fonts, `lang`/`dir`, viewport/theme-color, iOS web-app meta, no-flash theme script, Toaster, `ServiceWorker`), `manifest.ts` (PWA manifest), `icon.tsx` (`/icon/192|512|maskable` via ImageResponse), `apple-icon.tsx`, `globals.css` (design tokens light/dark: paper/ink, Signal Orange primary/seeker, Hider Teal, success/warning/danger; mobile baseline), `page.tsx` landing, `not-found.tsx`, `error.tsx`. Every other `page.tsx` is a thin server wrapper: metadata title + `<Suspense>` around a client screen from `src/components/screens/`: `start`, `signin`, `account`, `dashboard`, `join`, `invite/[token]`, `groups/new`, `groups/[id]`, `groups/[id]/matches/new` (setup, `?preset=` / `?zones=`), `matches/[id]` (lobby → live slot → results by state), `matches/[id]/edit`
- `src/components/ui/` — shadcn (base-nova, Base UI): button/input resized for touch (44 px), dialog, drawer, alert-dialog, dropdown-menu, switch, select, badge, card, field, label, separator, skeleton, toggle(-group), sonner (themed via `lib/theme`)
- `src/components/screens/` — one client component per route (data via `useApiQuery`, auth redirect on 401)
- `src/components/layout/` — `TopBar` (back + title + theme toggle), `Page` (content column, `wide` for two-column), `StickyFooter` (one primary action, safe-area), `ThemeToggle`, `ScreenFallback`, `ServiceWorker` (registers `/sw.js` in production, unregisters in dev)
- `src/components/common/` — `Sheet` (bottom drawer < 640 px, dialog above), `ConfirmDialog`, `States` (Loading/Error/Empty/Section), `UserAvatar`, `AvatarPicker` (emoji/colour/group icons), `ProfileFields`, `JoinCodeForm`, `CopyButton`, `QrCode` (`qrcode` lib)
- `src/components/group/` — `MembersList` (promote/demote/remove), `InvitePanel` (QR, code, link, share, regenerate), `PresetSections` (Quick start 2×2 + saved presets rename/duplicate/delete), `GroupForm`, `GroupSettingsSheet`
- `src/components/settings/` — `SettingsEditor` (generic renderer over `SETTINGS_FIELDS`/`SETTINGS_GROUPS`, Advanced per group, dependsOn, inline issues), `SettingControl`, `RulesSummary` (+ `shortRules`), `MatchSetup` (create/edit, presets, reset, save preset, play-area step, sticky summary)
- `src/components/lobby/` — `Lobby` (players, host controls incl. edit play area + sim bots, start blockers, ready; sim matches skip the GPS check), `ConsentSheet` (also used live to share again), `GpsCheck` (`useGpsCheck` + card with iOS/Android fixes)
- `src/components/match/` — `PlayerRow`/`RoleChip`/`PresenceDot`, `MatchBits` (StateBadge, CurrentMatchCard, ResultList), `Results` (highlights with player names), `LiveMatchSlot` (full-screen live match: HUD timer, status pill, banners, contextual action, tabs Map/Players/Goals/Events/Rules, host sheet, emergency/leave, event toasts + vibration, sim tap-to-move), `LiveMap` (zones, dynamic circle, own position + accuracy, teammates, pings, approx areas, controls), `RoleReveal` (target-lock reveal + role card, script helpers), `TagFlows` (tag sheet, show code, scan/code entry, tag/rescue prompts, rescue sheet), `QrScanner` (BarcodeDetector, `qr-scanner` fallback)
- `src/components/map/` — `maplibre.ts` (client-only MapLibre import + worker URL), `BaseMap` (map + style switching street/satellite/hybrid, context, `useGeoJson`, `MapMarker`, style pref), `zoneStyle.ts` (per-type colour/dash/icon/hatch, GeoJSON helpers, bounds), `ZoneLayers` (zone fill/hatch/lines + labels, `DynamicZoneLayer`), `MapControls` (≥ 44 px controls + layers sheet), `DragHandle` (draggable marker handle), `MapPreview` (static zones map), `ZoneEditorSlot` (zone editor: tools, handles, undo/redo, validation, timeline, preview as player, layouts, help)
- `src/components/zones/` — `ZonePanel` (selected-zone form + dynamic stages + scrubber), `zoneEdit.ts` (pure editing helpers; `zoneEdit.test.ts` also covers reveal timing)
- `src/lib/` — `gps.ts` (`useGps`: SPEC §10 send rule `shouldSend`, freshness, foreground resume, sim positions; `useWakeLock`; `gps.test.ts`), `app-icon.tsx` (icon artwork), `api.ts` (typed fetch, `ApiError`, 401 → `/start?next=`, `useApiQuery`, `safeNext`), `ws.ts` (`MatchSocket` reconnecting client + `useMatch`), `time-sync.ts` (server offset, `serverNow`), `hooks.ts` (`useServerNow`, `useMediaQuery`, `formatJoinCode`, `formatClock`), `theme.ts` + `theme-script.ts` (system/light/dark, localStorage), `utils.ts` (`cn`)
- `src/i18n/en.ts` — all UI strings; `src/i18n/index.ts` — `t()`, `tm()`, `formatDuration`, `locale`, `dir`
- `src/shared/` — pure game domain (no IO); barrel `index.ts`
  - `types.ts` — states, statuses, fixes, clock, events, `MatchView`
  - `schemas/` — zod: `settings.ts`, `zones.ts`, `ws.ts` (client/server messages, 8 KB cap), `api.ts` (REST bodies)
  - `defaults/` — `DEFAULT_SETTINGS`, `deepMerge`, `withDefaults`; `presets.ts` — 4 built-in presets
  - `settings/` — `meta.ts` (field registry for the settings UI), `validate.ts`, `summary.ts`, `hash.ts`
  - `geo/` — distance, destination, containment, signed distance, polygon validity (turf)
  - `zones/` — `validate.ts` (+ `ZONE_PRIORITY`), `timeline.ts` (`zoneStateAt`), `build.ts` (shrink templates, zonesAtPoint)
  - `location/` — freshness, presence, jump filter, boundary classifier, penalty pipeline
  - `visibility/` — approximation grid, ping snapshots, `buildView` (only producer of client coordinates)
  - `match/` — `stateMachine.ts`, `clock.ts` (deadlines, pause shift, pings), `roles.ts` (assignment, reveal script, rng)
  - `capture/` — capture/rescue rules, outcomes, proximity hint, scores, victory
  - `test-helpers.ts` — fixtures for unit tests (not in the barrel)
- `tests/integration/` — in-process server + real WS clients, injected clock: `helpers.ts` (env, cookie-jar `Api`, frame-recording `Sock`, lobby setup), `capture.test.ts` (scenario 1, QR/code, opIds, jail/rescue), `privacy.test.ts` (scenarios 2, 5, 8), `timeline.test.ts` (scenarios 3, 4, 7, pause, emergency), `api.test.ts` (auth, origin, groups, presets, authz, settings reset), `recovery.test.ts` (restart recovery, sim bots)
- `tests/e2e/` — Playwright (`npm run test:e2e`): `helpers.ts` (UI sign-up, in-page API, sim match setup, consent+ready), `onboarding.spec.ts` (onboarding → group → quick start → lobby), `sim-match.spec.ts` (bots → reveal → live map → host end → results; two players, 6-digit code capture → results)
- `public/` — `sw.js` (cache-first `/_next/static`, network-first navigations with `offline.html` fallback, never `/api` or `/ws`), `offline.html`
